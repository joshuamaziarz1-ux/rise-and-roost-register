# Rise & Roost Register

Self-service cash register, inventory, pickup, vendor, and customer rewards system for Rise & Roost.

Current version: **v4**

## v4 features

- Simple kiosk-style home screen with three large choices: Shop, Pickup Order, and The Roost
- Self-serve tap-to-buy checkout
- Exact-cash checkout with no change
- Vendors / brands with grouped products
- Saved item library and adjustable inventory
- Low-stock, sold-out, inventory history, and vendor reporting
- Customer pickup orders with pickup codes and inventory reservations
- **The Roost / Roost Club** member system
- Customer self-signup with name, phone number, and email
- Optional pickup-alert and store-update preferences
- Roost Club member contact information in Admin
- Egg-carton return tracking with customer-selectable quantity
- Configurable cartons-per-free-dozen reward threshold (default 12)
- Free-dozen reward redemption with automatic egg inventory deduction
- Carton return and reward history
- Admin carton-credit adjustment
- Admin PIN protection
- Backup and restore including Roost Club member data
- Daily dashboard
