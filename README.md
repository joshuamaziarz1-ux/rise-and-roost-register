# Rise & Roost Register

Self-service cash register and inventory system for Rise & Roost.

Current version: **v2**

## v2 features

- Self-serve tap-to-buy checkout
- Exact-cash checkout with no change
- Vendors / brands with grouped products
- Add, edit, hide, show, and safely delete vendors
- Saved item library
- Adjustable inventory with quick +/- controls and exact quantity entry
- Low-stock and sold-out handling
- Inventory adjustment history
- Vendor sales and payout reporting
- Void sales and restore inventory
- Customer pickup orders with pickup codes
- Pickup inventory reservations
- Ready / waiting / picked up / cancelled pickup states
- Paid / unpaid pickup handling
- Admin PIN protection
- Backup and restore
- Daily dashboard
